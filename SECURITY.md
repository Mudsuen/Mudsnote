# Security

## Reporting Security Issues

Please do not disclose security issues publicly before maintainers have reviewed them. Open a private report or contact the maintainer from the GitHub profile when possible.

## Secrets

Do not commit API keys, provider tokens, signing certificates, passwords, or other credentials to this repository.

## AI Boundary

Mudsnote does not send notes to AI providers unless the user explicitly invokes an AI command. Current AI support targets local Ollama by default and keeps remote-provider support out of the first implementation slice.
